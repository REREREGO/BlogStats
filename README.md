# BlogStats

Public aggregate page-view counts for MyBlog. Contains only timestamps, cumulative counts, and their collector. No source, drafts, visitor identifiers or credentials.

Hourly collection retains 35 days; original counter key is preserved. Data: https://rererego.github.io/BlogStats/history.json . Source: history.json on main. Uses this repository's own GITHUB_TOKEN; no access to MyBlog required.
